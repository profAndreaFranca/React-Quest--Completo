# React Quest — Central de Missões e Evolução Dev
## Descrição do projeto
O React Quest é um projeto educacional de desenvolvimento web que propõe a construção progressiva de uma plataforma gamificada para acompanhar a jornada de aprendizagem de programação.

A aplicação reúne funcionalidades como gerenciamento de missões, cadastro de projetos, portfólio, acompanhamento de XP por tecnologia e conquistas. Ao longo do curso, a plataforma evolui com a integração de APIs, banco de dados, autenticação de usuários e inteligência artificial.

O projeto utiliza principalmente React, JavaScript, HTML e CSS, além de ferramentas e serviços como Git, GitHub, Vite e Supabase.

## Objetivo do projeto
Ensinar desenvolvimento web de forma prática, progressiva e motivadora, proporcionando aos alunos a experiência de construir uma aplicação cada vez mais próxima de um sistema real.

O React Quest busca desenvolver habilidades de programação, pensamento computacional, resolução de problemas, organização de código e utilização consciente de ferramentas de inteligência artificial.

Além disso, pretende estimular a autonomia, a criatividade e o protagonismo dos alunos, permitindo que acompanhem sua evolução e construam um projeto que poderá integrar seus portfólios profissionais.

## Metodologia utilizada
O projeto utiliza uma metodologia ativa, baseada em projetos (Project-Based Learning — PBL), combinada com gamificação, aprendizagem progressiva e uso orientado de inteligência artificial.

As aulas seguem uma abordagem prática e incremental, na qual cada novo conceito é apresentado a partir de um problema real da aplicação.

A metodologia também incorpora:
- Shuhari: aprender com orientação, experimentar adaptações e desenvolver autonomia.
- Aprendizagem mão na massa: construir, testar, investigar erros e aprimorar funcionalidades.
- Gamificação: utilizar missões, XP, níveis e conquistas como elementos motivadores.
- IA como copiloto: compreender primeiro os conceitos e utilizar a inteligência artificial para acelerar tarefas repetitivas, sempre com revisão e validação do código.
- Experiência CodeMinds: proporcionar aulas envolventes, com desafios, descobertas, resultados visíveis e valorização das conquistas individuais.
A proposta segue o princípio “Primeiro eu entendo. Depois eu acelero”, incentivando os alunos a utilizarem a tecnologia de maneira crítica, criativa e responsável.

O resultado esperado é uma aprendizagem significativa, em que os estudantes não apenas reproduzem códigos, mas compreendem como diferentes tecnologias se conectam na construção de uma aplicação web completa.
